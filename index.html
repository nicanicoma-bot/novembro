Aprenda Flexbox

Flexbox é um conceito do CSS que visa organizar os elementos de uma página HTML dentro de seus containers de forma dinâmica.

Display flex

O display: flex é uma propriedade do CSS Flexible Box Layout (Flexbox) que transforma um elemento em um contêiner flexível.

justify content

justify-content no CSS é utilizada para distribuir espaço entre e entre os itens dentro de um layout flexível.

Align itens

align-items no CSS controla o alinhamento vertical dos itens dentro de um container flexível ou grid.

flex wrap

Flex-wrap define se os itens flexíveis devem quebrar para novas linhas ou não.

Layout Responsivo

significa que a página se adapta automaticamente ao tamanho da tela — seja celular, tablet ou computador.

Alinhamento Perfeito

se refere a colocar um elemento exatamente no centro da área disponível, tanto no eixo horizontal quanto no vertical.

Distribuicao de Espacos

significa como os elementos dentro de um contêiner são organizados e espaçados entre si.
